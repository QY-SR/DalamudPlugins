# 定型文快速筛选

用轻量搜索窗替代 FFXIV 原生定型文的逐级菜单查找。

## 使用

- 输入 `/qat` 打开窗口。
- 也可以直接输入 `/qat xk`，打开后立即搜索“辛苦了”一类首字母匹配。
- 支持中文、拼音首字母、定型文分类名称。
- `↑` / `↓` 选择，`Enter` 放入聊天输入框；`Esc` 关闭。
- 点击星标收藏；空搜索时优先显示收藏和最近使用。

插件只把固定的定型文词条放入聊天输入框，不会自动发送，也不会伪造自定义词条。最终发送完全由用户手动确认。

## 已知限制

首字母由 GB2312 常用汉字规则生成。少量生僻字和多音字可能无法命中预期读音，此时仍可用中文直接搜索。
