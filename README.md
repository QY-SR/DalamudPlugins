# 战斗模型屏蔽

一个面向 Dalamud API 15 的轻量插件：

- 仅屏蔽具有真实网络实体 ID 的地图玩家本体、武器、坐骑及附属模型；明确排除冒险者铭牌和角色肖像的预览对象。
- 可选择“仅在战斗中屏蔽”或“常驻屏蔽”。
- 可选择不屏蔽已经死亡的玩家，方便选中并复活其他玩家。
- 可选择不屏蔽好友。
- 可选择不屏蔽正在以自己为目标的玩家。
- 可选择同时隐藏非小队玩家的场景姓名板；不会影响角色肖像。
- 自己和小队成员始终不会被屏蔽。

## 使用

1. 构建项目。
2. 在 Dalamud 的开发者插件中加载生成的 `CombatModelBlocker.dll`。
3. 输入 `/cmb` 打开设置。

默认设置为“仅在战斗中屏蔽”并“不屏蔽已经死亡的玩家”。

## 构建

需要 .NET SDK 和本机已安装/可还原的 `Dalamud.NET.Sdk` 15.0.0：

```powershell
dotnet build -c Release
```

构建后的开发加载目录位于 `bin\x64\Release\CombatModelBlocker`。

## 注意

这是纯客户端显示修改，不会发送额外网络请求，也不会自动执行任何游戏操作。卸载插件、关闭插件、离开战斗或切换设置时，插件会恢复由它隐藏的模型。
