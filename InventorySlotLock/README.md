# 背包道具保护

保护角色背包四页中的指定道具：自动整理时固定其位置，但仍可正常选中、使用和手动拖动；插件会阻止出售、丢弃和任务上交。

## 使用方法

- 输入 `/isl` 打开背包映射窗口。
- 窗口按游戏当前显示顺序展示 4 页、每页 35 格，并显示物品图标、名称和数量。
- 左键点击有物品的格子即可保护或解除保护；空格不能锁定。
- 也可以右键游戏背包中的物品，选择“锁定此格”或“解除锁定此格”。
- 手动拖动受保护道具后，保护会跟随到新的背包格子。
- 游戏原生背包中的受保护格会显示金橙色边框和右上角小锁，不影响鼠标操作。
- 尝试出售或上交任务时会被拒绝并在聊天栏提示；丢弃会在底层调用处被拒绝。

目前只追踪角色背包第 1～4 页之间的移动。
