# 新月岛宝藏标记

Dalamud API 15 插件，用于标记新月岛附近已经生成并加载到客户端的宝箱和被啃过的胡萝卜。

- 纯本地虚拟场地标点：地面圆环、立柱、图标和距离。
- 宝箱、萝卜可分别开关。
- 检测结果按距离排序。
- 持久记录已经发现但尚未开启的宝箱；靠近并确认宝箱消失后自动移除。
- 发现新目标时自动在默语频道输出一次可点击地图坐标。
- 可在列表中手动再次回显坐标，不会发送给其他玩家。
- 多语言名称识别和自定义 Base ID 扫描器。

命令：`/ocmark`

插件不会写入地图旗标或向服务器放置真正的场地标点，只读取本地对象表并绘制覆盖层；不自动移动、不自动寻路，也不自动与宝箱或萝卜交互。
